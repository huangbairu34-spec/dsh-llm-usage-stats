# dsh-llm-usage-stats

统计**不同大模型（provider/model）用量**的 DSH 插件（组合包）。
它把每个会话里模型实际报告的 token 计量（`TokenUsage`）按 `provider/model` 跨会话累计，
随时用 `/usage` 命令查看报表。

## 功能

- **按模型分类**：以 `provider/model`（如 `deepseek/deepseek-chat`）为粒度累计。
- **完整 token 口径**：输入（未缓存）、缓存读、缓存写、输出、推理 token 分列，
  并派生「计费输入」（= 输入 + 缓存读 + 缓存写）与「总计」（= 计费输入 + 输出）。
- **多维度**：全部时间、最近 N 天（含按日明细）、当前会话。
- **跨会话、跨重启累计**：账本独立持久化，进程重启、会话 resume、插件热重载都不丢、不重复计数。
- **零依赖**：不引用任何第三方包，安装即用；纯本地数据，无网络、无遥测。

## 安装

在 DSH 的 **profile 目录**里把这个目录作为本地包安装（Windows 路径）：

```powershell
dsh plugin --profile <你的 profile> add "E:\设想\用量记录"
```

也支持：

- Web 界面 → 侧边栏「插件」页 → 安装本地目录；
- 会话里让 agent 用 `plugin_manager` 工具安装（spec 同样是目录路径
  `E:\设想\用量记录`，或 `file:E:/设想/用量记录`）。

安装即启用（组合包 `cordis.patch.yml` 自动挂载插件行），无需重启；
开发期改动可用插件页/HMR 热重载，否则重启生效。卸载组合包即停止统计（账本文件保留）。

> 组合包零依赖，不访问 npm registry；本地目录安装直接读取本目录的 `package.json`。

## 用法

| 命令 | 含义 |
| --- | --- |
| `/usage` | 全部时间按模型汇总 + 最近 7 天按日明细 |
| `/usage session` | 当前会话的按模型用量 |
| `/usage <天数>` | 最近 N 天按模型汇总 + 按日明细（如 `/usage 30`） |

参数也接受 `days 7`、`天 7`、`s` 等写法；写错会给出用法提示。

## 统计口径

- **数据来源**：会话事件流中模型**实际报告**的计量
  （`assistant/message` 事件的 `usage`，与 `@deepseek-ai/dsh-llm` 的 `TokenUsage` 同源）。
- **调用数**：携带 `usage` 的模型回复数。适配器未报告计量的调用不计入
  （报告里会注明），`assistant/attempt`（模型未输出的尝试）不计。
- **各 token 计数互斥**：`inputTokens` 只算未缓存输入；计费输入 = 输入 + 缓存读 + 缓存写。
- **归因**：按会话当前 call config 的 `provider/model` 归属（`request/header` 记录的配置；
  切换模型后新用量归到新模型）。会话建立前的用量若无配置可依，归入 `unknown/unknown`。
- **去重**：每会话维护事件水位，恢复/回放不重复计数；fork 出的新会话不重复计入父会话的继承历史。
- **费用**：不折算货币。Token 口径已足够做用量统计；如需费用可按各渠道单价自行换算。

## 数据文件

账本写在 `<DSH home>/model-usage/usage.json`
（`DSH_HOME` 环境变量指定的目录，否则 `~/.dsh`）。

- JSON 明文，结构：`{ version, updatedAt, sessions: {会话水位/归因/按模型计数}, models: {按模型总计}, days: {日期 → 按模型计数} }`。
- 原子写入（临时文件 + rename），写盘防抖 500ms，插件卸载/热重载前强制落盘。
- 可随时备份、删除（删除即清零重新累计）或用任意脚本二次加工。

## 已知限制

- 仅统计适配器报告了 token 计量的调用；请求失败、被中断且未报告计量的调用无法计入。
- 中断的回复按适配器**已报告**的部分计。
- 同一会话若同时被两个进程写入同一账本，极端情况下可能个别重复（正常单实例使用无此问题）。
- 不统计非模型类成本（如图像生成、网页检索等）。

## 开发

```text
E:\设想\用量记录
├─ package.json        # dsh.bundle.patch 指向 cordis.patch.yml
├─ cordis.patch.yml    # 组合包补丁：安装即启用本插件
├─ lib
│  ├─ index.js         # 插件入口：事件折叠 + /usage 命令注册
│  ├─ store.js         # 用量账本（纯数据折叠 + JSON 持久化）
│  └─ report.js        # 报表渲染（等宽中文表格）
└─ test                # node --test 测试（含端到端烟测）
```

运行测试：

```powershell
node --test
```

损坏文件容错、报表渲染、`/usage` 参数解析，以及「假 ctx 驱动真实插件」的端到端链路。
